# Artemis macOS App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Artemis into a double-clickable `Artemis.app` that opens the Command Center in its own window, starting the Node server itself when one isn't already running.

**Architecture:** A small AppKit app written in Swift, compiled with `swiftc` and assembled into a bundle by hand (no full Xcode on this machine, so no `xcodebuild`). It hosts the existing web UI in a `WKWebView` pointed at `http://127.0.0.1:4100`, spawns `node server.js` as a child process when needed, and hands outbound links to macOS. No npm dependencies are added — Artemis has no `node_modules` today and keeps it that way.

**Tech Stack:** Swift 6.4 (Command Line Tools), AppKit, WebKit, `codesign` ad-hoc signing. Node v22 located at runtime, not bundled.

## Global Constraints

- **No npm dependencies.** Nothing may add a `node_modules` directory.
- **Swift only via `swiftc`.** `xcodebuild` is unavailable (Command Line Tools only, no Xcode).
- **Target:** macOS 26.0 minimum (`LSMinimumSystemVersion`), arm64.
- **Never kill a server the app did not start.** `ownsServer` gates every termination.
- **No changes to `public/main.js`.** The app adapts to the page, not the reverse.
- **All source lives under `app/`.** Nothing outside `app/` changes except docs.
- **Repo path** is baked into `Info.plist` as `ArtemisRoot` by `build.sh`, overridable by the `ARTEMIS_ROOT` environment variable.
- **Port** is `4100` unless `ARTEMIS_PORT` says otherwise.

## File Structure

| File | Responsibility |
|---|---|
| `app/Sources/main.swift` | Entry point; picks run mode from argv |
| `app/Sources/NodeLocator.swift` | Finds a usable `node` binary |
| `app/Sources/ServerController.swift` | Probe / attach / spawn / terminate |
| `app/Sources/BrowserBridge.swift` | `WKUIDelegate` — link routing + mic permission |
| `app/Sources/AppDelegate.swift` | Window, WKWebView, lifecycle, alerts |
| `app/Info.plist.in` | Template; `build.sh` substitutes root path |
| `app/build.sh` | Compile, assemble bundle, ad-hoc sign |
| `app/test-app.sh` | Shell tests driving the binary's hidden CLI flags |
| `app/README.md` | Build, run, troubleshoot, smoke checklist |

**Why several files rather than the single `Artemis.swift` the spec sketched:** each unit above is independently testable and small enough to hold in context. `swiftc` compiles a file list, so there is no cost to splitting.

**Testing approach.** XCTest is not reliably available without Xcode, so the pure logic is exercised through hidden CLI flags on the same binary (`--find-node`, `--probe`), driven by `app/test-app.sh`. GUI behaviour is covered by the compat-check mode and a written smoke checklist.

```swift
import AppKit

enum RunMode {
    case normal
    case compatCheck
}

let argv = CommandLine.arguments

// Hidden non-GUI modes are handled before AppKit starts so they can print and exit.
if argv.contains("--find-node") {
    if let node = NodeLocator.find() {
        print(node.path)
        exit(0)
    }
    FileHandle.standardError.write("no node found\n".data(using: .utf8)!)
    exit(1)
}

if let i = argv.firstIndex(of: "--probe"), i + 1 < argv.count, let url = URL(string: argv[i + 1]) {
    print(ServerController.probe(statusURL: url).rawValue)
    exit(0)
}

let mode: RunMode = argv.contains("--compat-check") ? .compatCheck : .normal
let port = ProcessInfo.processInfo.environment["ARTEMIS_PORT"] ?? "4100"
let base = URL(string: "http://127.0.0.1:\(port)/")!

let app = NSApplication.shared
let delegate = AppDelegate(mode: mode, url: base)
app.setActivationPolicy(.regular)
app.delegate = delegate
app.run()
```

```swift
        out.micError = String(e && e.name);
```

```bash
#!/usr/bin/env bash
# Builds Artemis.app. No Xcode required — swiftc plus a hand-assembled bundle.
set -euo pipefail

HERE="$(cd "$(dirname "$0")" && pwd -P)"
ROOT="$(cd "$HERE/.." && pwd -P)"
OUT="$HERE/build"
APP="$OUT/Artemis.app"

rm -rf "$APP"
mkdir -p "$APP/Contents/MacOS" "$APP/Contents/Resources"

# The repo path is baked in so the app always runs the current working copy.
sed "s|__ARTEMIS_ROOT__|$ROOT|g" "$HERE/Info.plist.in" > "$APP/Contents/Info.plist"

swiftc -O \
  -o "$APP/Contents/MacOS/Artemis" \
  -target arm64-apple-macos26.0 \
  "$HERE"/Sources/*.swift

# Ad-hoc signature: enough for the microphone prompt to appear. It changes on
# every build, so macOS may re-ask for mic access after a rebuild.
codesign --force --sign - --identifier com.artemis.desktop "$APP" >/dev/null 2>&1 || {
  echo "warning: codesign failed; the microphone prompt may not appear" >&2
}

echo "built $APP"
```

```bash
#!/usr/bin/env bash
# Drives the app binary's hidden CLI flags. XCTest needs Xcode, which isn't
# installed, so the testable logic is exercised through the real binary.
set -uo pipefail

HERE="$(cd "$(dirname "$0")" && pwd -P)"
ROOT="$(cd "$HERE/.." && pwd -P)"
BIN="$HERE/build/Artemis.app/Contents/MacOS/Artemis"
NODE="$($BIN --find-node 2>/dev/null || true)"
fails=0
ok()   { echo "  ✓ $1"; }
bad()  { echo "  ✗ $1"; fails=$((fails+1)); }

# 1) it finds a node that actually runs
if [ -n "$NODE" ] && "$NODE" -e 'process.exit(0)' 2>/dev/null; then
  ok "finds a working node ($NODE)"
else
  bad "could not find a working node"
fi

# 2) a closed port probes as 'none'
PORT=$(node -e 'const s=require("net").createServer();s.listen(0,()=>{console.log(s.address().port);s.close()})')
sleep 0.3
[ "$($BIN --probe http://127.0.0.1:$PORT/api/status)" = "none" ] \
  && ok "closed port probes as none" || bad "closed port should probe as none"

# 3) a real Artemis probes as 'artemis'
DATA=$(mktemp -d)
PORT=$(node -e 'const s=require("net").createServer();s.listen(0,()=>{console.log(s.address().port);s.close()})')
sleep 0.3
( cd "$ROOT" && PORT=$PORT ARTEMIS_HOST=127.0.0.1 ARTEMIS_HTTPS= STRIPE_SECRET_KEY= \
    ARTEMIS_DATA_DIR="$DATA" "$NODE" server.js >/dev/null 2>&1 & echo $! > "$DATA/pid" )
for _ in $(seq 1 60); do
  [ "$($BIN --probe http://127.0.0.1:$PORT/api/status)" = "artemis" ] && break
  sleep 0.5
done
[ "$($BIN --probe http://127.0.0.1:$PORT/api/status)" = "artemis" ] \
  && ok "a real Artemis probes as artemis" || bad "real Artemis should probe as artemis"
kill "$(cat "$DATA/pid")" 2>/dev/null

# 4) a non-Artemis HTTP server probes as 'foreign'
PORT=$(node -e 'const s=require("net").createServer();s.listen(0,()=>{console.log(s.address().port);s.close()})')
sleep 0.3

  && ok "a stranger on the port probes as foreign" || bad "stranger should probe as foreign"
```

```swift
import Foundation

/// Finds a `node` binary.
///
/// This is not as simple as it looks: an app launched from Finder inherits none
/// of the user's shell PATH, so `node` is invisible unless it is searched for
/// explicitly. The login-shell fallback is last because spawning a shell is slow.
enum NodeLocator {
    static let searched = [
        "$ARTEMIS_NODE",
        "~/.local/bin/node",
        "/opt/homebrew/bin/node",
        "/usr/local/bin/node",
        "/usr/bin/node",
        "(login shell PATH)"
    ]

    static func find() -> URL? {
        let fm = FileManager.default
        let env = ProcessInfo.processInfo.environment

        if let override = env["ARTEMIS_NODE"], fm.isExecutableFile(atPath: override) {
            return URL(fileURLWithPath: override)
        }
        let home = fm.homeDirectoryForCurrentUser.path
        for path in ["\(home)/.local/bin/node", "/opt/homebrew/bin/node",
                     "/usr/local/bin/node", "/usr/bin/node"] {
            if fm.isExecutableFile(atPath: path) { return URL(fileURLWithPath: path) }
        }
        return fromLoginShell()
    }

    private static func fromLoginShell() -> URL? {
        let shell = ProcessInfo.processInfo.environment["SHELL"] ?? "/bin/zsh"
        let p = Process()
        p.executableURL = URL(fileURLWithPath: shell)
        p.arguments = ["-lc", "command -v node"]
        let pipe = Pipe()
        p.standardOutput = pipe
        p.standardError = FileHandle.nullDevice
        do { try p.run() } catch { return nil }
        p.waitUntilExit()
        let out = String(data: pipe.fileHandleForReading.readDataToEndOfFile(), encoding: .utf8)?
            .trimmingCharacters(in: .whitespacesAndNewlines) ?? ""
        guard !out.isEmpty, FileManager.default.isExecutableFile(atPath: out) else { return nil }
        return URL(fileURLWithPath: out)
    }
}
```

- [ ] **Step 4: Write ServerController**

Create `app/Sources/ServerController.swift`:

```swift
import Foundation

enum ProbeResult: String {
    case artemis
    case foreign
    case none
}

enum ServerError: Error {
    case nodeMissing
    case rootMissing(String)
    case foreignServer
    case timeout(String)
}

/// Owns the Node server — but only if it started it.
///
/// The user often runs `node server.js` in a terminal. Attaching to that and
/// then killing it on quit would be a nasty surprise, so `ownsServer` gates
/// every termination.
final class ServerController {
    let root: URL
    let port: String
    private(set) var ownsServer = false
    private var process: Process?
    private var stderrBuffer = ""
    private let stderrLock = NSLock()

    let logURL: URL = {
        let dir = FileManager.default.homeDirectoryForCurrentUser
            .appendingPathComponent("Library/Logs/Artemis", isDirectory: true)
        try? FileManager.default.createDirectory(at: dir, withIntermediateDirectories: true)
        return dir.appendingPathComponent("server.log")
    }()

    var statusURL: URL { URL(string: "http://127.0.0.1:\(port)/api/status")! }

    init(root: URL, port: String) {
        self.root = root
        self.port = port
    }

    /// Is something answering on that URL, and is it Artemis?
    ///
    /// Identified by fields only Artemis serves. A bare "it responded" check
    /// would happily attach the app to an unrelated dev server.
    static func probe(statusURL: URL, timeout: TimeInterval = 0.5) -> ProbeResult {
        var request = URLRequest(url: statusURL)
        request.timeoutInterval = timeout
        var result = ProbeResult.none
        let sem = DispatchSemaphore(value: 0)
        URLSession.shared.dataTask(with: request) { data, response, _ in
            defer { sem.signal() }
            guard let http = response as? HTTPURLResponse, http.statusCode == 200,
                  let data = data,
                  let json = try? JSONSerialization.jsonObject(with: data) as? [String: Any]
            else { return }
            result = (json["chatEnabled"] != nil && json["localWake"] != nil) ? .artemis : .foreign
        }.resume()
        _ = sem.wait(timeout: .now() + timeout + 0.5)
        return result
    }

    /// Attach if Artemis is already up, otherwise spawn one.
    /// - Returns: `true` when it spawned a server, `false` when it attached.
    @discardableResult
    func start(readyTimeout: TimeInterval = 20) throws -> Bool {
        switch Self.probe(statusURL: statusURL) {
        case .artemis: ownsServer = false; return false
        case .foreign: throw ServerError.foreignServer
        case .none: break
        }

        guard FileManager.default.fileExists(atPath: root.appendingPathComponent("server.js").path)
        else { throw ServerError.rootMissing(root.path) }
        guard let node = NodeLocator.find() else { throw ServerError.nodeMissing }

        let p = Process()
        p.executableURL = node
        p.arguments = ["server.js"]
        p.currentDirectoryURL = root
        // Environment is inherited so server.js loads .env exactly as it does
        // from a terminal; only the port is forced.
        var env = ProcessInfo.processInfo.environment
        env["PORT"] = port
        p.environment = env

        let pipe = Pipe()
        p.standardOutput = pipe
        p.standardError = pipe
        pipe.fileHandleForReading.readabilityHandler = { [weak self] h in
            let data = h.availableData
            guard !data.isEmpty, let text = String(data: data, encoding: .utf8) else { return }
            self?.stderrLock.lock()
            self?.stderrBuffer += text
            self?.stderrLock.unlock()
            if let fh = try? FileHandle(forWritingTo: self?.logURL ?? URL(fileURLWithPath: "/dev/null")) {
                fh.seekToEndOfFile(); fh.write(data); try? fh.close()
            }
        }
        FileManager.default.createFile(atPath: logURL.path, contents: nil)
        try p.run()
        process = p
        ownsServer = true

        let deadline = Date().addingTimeInterval(readyTimeout)
        while Date() < deadline {
            if Self.probe(statusURL: statusURL) == .artemis { return true }
            if !p.isRunning { throw ServerError.timeout(recentStderr) }
            Thread.sleep(forTimeInterval: 0.25)
        }
        throw ServerError.timeout(recentStderr)
    }

    /// Last 30 lines the server printed — the actual reason it failed.
    var recentStderr: String {
        stderrLock.lock(); defer { stderrLock.unlock() }
        return stderrBuffer.split(separator: "\n").suffix(30).joined(separator: "\n")
    }

    func stop() {
        guard ownsServer, let p = process, p.isRunning else { return }
        p.terminate()
        let deadline = Date().addingTimeInterval(3)
        while p.isRunning && Date() < deadline { Thread.sleep(forTimeInterval: 0.1) }
        process = nil
    }
}
```

```swift
import AppKit
import WebKit

/// Sends links to the user's real browser, and grants the microphone.
///
/// The subtle part is `window.open`. Returning nil from
/// `createWebViewWith` makes `window.open()` evaluate to null in the page —
/// and public/main.js:102 reads exactly that to decide the pop-up was blocked:
///
///     let w = null;
///     try { w = window.open(url, "_blank"); } catch (e) {}
///     if (w) return true;
///     showOpenPill(url, label);
///
/// Without the shim below, Artemis announces "pop-up blocked" every single time
/// while the tab opens fine behind her. The shim returns a truthy stub instead,
/// so main.js needs no changes and stays correct in a plain browser too.
final class BrowserBridge: NSObject, WKUIDelegate, WKScriptMessageHandler {
    static let messageName = "artemisOpenExternal"

    static let openShimJS = """
    (function () {
      const post = (u) => { try { window.webkit.messageHandlers.\(messageName).postMessage(String(u)); } catch (e) {} };
      window.open = function (url) {
        if (url) post(url);
        // Truthy stub: the page uses the return value to detect pop-up blocking,
        // and nothing was blocked — macOS opened it.
        return { closed: false, focus() {}, close() {}, postMessage() {}, document: null };
      };
      document.addEventListener("click", (e) => {
        const a = e.target && e.target.closest && e.target.closest('a[href]');
        if (!a) return;
        const href = a.getAttribute("href") || "";
        if (/^https?:/i.test(href) && !href.includes("127.0.0.1") && !href.includes("localhost")) {
          e.preventDefault();
          post(a.href);
        }
      }, true);
    })();
    """

    private static func openExternally(_ raw: String) {
        guard let url = URL(string: raw), let scheme = url.scheme?.lowercased(),
              scheme == "http" || scheme == "https" else { return }
        NSWorkspace.shared.open(url)
    }

    func userContentController(_ c: WKUserContentController, didReceive message: WKScriptMessage) {
        guard message.name == Self.messageName, let raw = message.body as? String else { return }
        Self.openExternally(raw)
    }

    // Belt and braces: anything that still reaches the native path goes out too.
    func webView(_ wv: WKWebView, createWebViewWith cfg: WKWebViewConfiguration,
                 for action: WKNavigationAction, windowFeatures: WKWindowFeatures) -> WKWebView? {
        if let url = action.request.url { Self.openExternally(url.absoluteString) }
        return nil
    }

    /// The only origin ever loaded is our own loopback server, so this is a grant.
    /// The Info.plist usage string is what the user actually sees.
    func webView(_ wv: WKWebView,
```

```swift
    // MARK: failure presentation

    private func alert(_ title: String, _ body: String, style: NSAlert.Style = .critical) {
        let a = NSAlert()
        a.alertStyle = style
        a.messageText = title
        a.informativeText = body
        a.addButton(withTitle: "Quit")
        a.runModal()
        NSApp.terminate(nil)
    }

    private func presentStartupFailure(_ error: Error) {
        switch error {
        case ServerError.nodeMissing:
            alert("Artemis can't find Node.",
                  "Looked in:\\n" + NodeLocator.searched.joined(separator: "\\n") +
                  "\\n\\nSet ARTEMIS_NODE to the full path of your node binary and try again.")
        case ServerError.rootMissing(let path):
            alert("Artemis can't find its files.",
                  "Expected server.js in:\\n\(path)\\n\\n" +
                  "If you moved the project, rebuild the app with app/build.sh, " +
                  "or set ARTEMIS_ROOT to the new location.")
        case ServerError.foreignServer:
            alert("Port \(server.port) is already in use.",
                  "Something is answering on that port, but it isn't Artemis. " +
                  "Stop it and reopen Artemis, or set ARTEMIS_PORT to a free port.")
        case ServerError.timeout(let log):
            alert("The Artemis server didn't start.",
                  (log.isEmpty ? "It produced no output." : "Last output:\\n\\n" + log) +
                  "\\n\\nFull log: \(server.logURL.path)")
        default:
            alert("Artemis failed to start.", "\(error)\\n\\nLog: \(server.logURL.path)")
        }
    }

    private func presentLoadFailure(_ error: Error) {
        let a = NSAlert()
        a.alertStyle = .warning
        a.messageText = "Couldn't load the Artemis interface."
        a.informativeText = "\(error.localizedDescription)\\n\\nLog: \(server.logURL.path)"
        a.addButton(withTitle: "Retry")
        a.addButton(withTitle: "Quit")
        if a.runModal() == .alertFirstButtonReturn {
            webView.load(URLRequest(url: url))
        } else {
            NSApp.terminate(nil)
        }
    }
```

````markdown
# Artemis.app

A windowed macOS wrapper around the Artemis server. Double-click it; it starts
the server if one isn't running and opens the Command Center in its own window.

## Build

```bash
bash app/build.sh
open app/build/Artemis.app
```

Needs the Xcode Command Line Tools (`xcode-select --install`) — not full Xcode.
No npm dependencies are added.

Drag `app/build/Artemis.app` to `/Applications` once and it behaves like any
other Mac app.

## How it behaves

- **Already running a server on 4100?** The app attaches to it and leaves it
  alone when you quit. It never kills a server it didn't start.
- **Nothing running?** It starts `node server.js` itself and stops that one when
  you quit.
- **Links** ("open youtube", a map, a video) go to your default browser. In the
  app there is no pop-up blocking, so hands-free opening always works.
- **Closing the window quits the app.**

## Configuration

| Variable | Effect |
|---|---|
| `ARTEMIS_ROOT` | Where the project lives (default: baked in at build time) |
| `ARTEMIS_NODE` | Full path to a `node` binary |
| `ARTEMIS_PORT` | Port to use (default `4100`) |

Server output is logged to `~/Library/Logs/Artemis/server.log`.

## Known caveats

- **The microphone prompt can reappear after a rebuild.** macOS ties the
  permission to the code signature, and ad-hoc signing produces a new identity
  each build. It settles once you stop rebuilding.
- **The browser wake-word fallback is unavailable** — WKWebView has no
  `webkitSpeechRecognition`. This is fine: the on-device openWakeWord engine is
  the primary path and is unaffected (iPhone Safari has the same gap).
- **Moving the project** breaks the baked-in path until you rebuild, or set
  `ARTEMIS_ROOT`.

## Tests

```bash
bash app/test-app.sh                                        # node discovery + probing
./app/build/Artemis.app/Contents/MacOS/Artemis --compat-check   # web API support
```

## Smoke checklist

- [ ] Double-clicking with no server running opens the window
- [ ] Wake word fires and a spoken command executes
- [ ] "open youtube" opens the default browser, with no "pop-up blocked"
- [ ] Quitting with a hand-started server leaves that server running
- [ ] Quitting a server the app started stops it
````
